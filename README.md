Entry for the make.fun bounty [The plan make.fun will carry out in public](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138).

A Node 22 program (`main.ts`) that writes one short plan — a plan an AI agent can carry out itself to turn $100 into as much money as possible in 30 days — to `/output/entry.txt`.

## The plan

> Buy a $12 domain and $20 hosting. Build a niche AI micro-tool: an invoice generator for freelancers. Publish 30 SEO pages in 10 days and launch on Product Hunt. Charge $9/month, add affiliate links, reinvest all revenue into ads. Target: 200 users, $1,800/month by day 30.

## Run

```sh
node main.ts
```

This writes the plan text to `/output/entry.txt`. The output is deterministic: byte-identical on every run.
